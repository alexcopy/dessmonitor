BLOCKERS

1. Direct transport calls can write SBU, not only Utility.

Location: app/control/easun_live_output_transport.py:119-127.

After read_catalogue(), _advertised_priority_keys contains every advertised
key. write_output_priority() accepts any member of that set, including the
SBU key "2". The approved plan requires the dedicated transport itself to
construct only the exact advertised Utility request. The coordinator's exact
catalogue check does not make the transport boundary safe when the transport
is called directly.

An isolated fake-only probe called read_catalogue() followed by
write_output_priority("2") and observed a ctrlDevice request with
id=los_output_source_priority and val=2.

Minimal fix: retain the exact key whose catalogue label is Utility and reject
every other key in write_output_priority(), with tests for SBU, Solar, charger,
and voltage keys. Keep the coordinator's complete exact-map gate as a separate
check.

2. Live receipt freshness is anchored to a timestamp captured before the live
   reads, making the successful live path impossible for normal network
   responses.

Location: app/control/easun_utility_hold.py:117-149 and 217-220.

The method sets now from caller-supplied evaluated_at before calling the live
transport. CatalogueRead and SettingRead receive local receipt timestamps
after those calls, but _fresh() compares them with that earlier now and
rejects any normal response that is even slightly newer as future data. A
fake-only probe with receipt_at=evaluated_at+1 second returned
CATALOGUE_MAPPING_UNVERIFIED and issued zero writes.

Minimal fix: keep the gated charger/setting observations checked against the
decision timestamp, but validate each live response against a fresh aware
receipt-check time captured after that response (and validate post-write
readback against its own post-read time). Add future, exact-boundary, and
normal-after-evaluated_at tests without weakening the 0 <= age <= limit rule.

3. The required pre-write state-race barrier is absent.

Location: app/control/easun_utility_hold.py:147-211.

The coordinator reads the current setting before acquiring the shared journal
lock, then proceeds directly from the lock to intent and write. It never
re-reads the output priority while holding the lock immediately before the
intent. An external change from SBU to Solar after the first read therefore
still permits a Utility write. The approved plan explicitly requires a
readback race to block further writes.

Minimal fix: after acquiring the lock and before intent, perform a fresh
readback, require a fresh parsed SBU value matching the gated observation,
and refuse with zero write if it is changed, stale, invalid, or unavailable.
Add a fake transport/journal race regression test.

4. The pinned request boundary does not enforce the plan's no-redirect
   invariant.

Location: app/control/easun_live_output_transport.py:80-85 and app/api.py:353-354.

LiveDessTransport delegates to DessAPI._do_api_request(), whose
urllib.request.urlopen() uses the default redirect handler. The transport
pins the initial URL but cannot reject a redirect from that helper. The plan
requires redirects and alternate endpoints to be rejected before any live
request. This is not covered by the current fake adapter test.

Minimal fix: provide a reviewed request boundary that disables/rejects
redirects while preserving the exact endpoint and signing contract, or amend
the approved plan before implementation if that cannot be done without a
forbidden app/api.py change. Add a fake/request-boundary test proving a
redirect is refused.

assert all approved acceptance cases. In particular it lacks coordinator tests
for concurrent calls, the post-lock race above, stale/future live catalogue

key. The emergency test creates an unused SimpleNamespace and therefore does

   exception.

   shielded read-only reconciliation and append a POST_WRITE_READBACK value

   event.

   durable row status, reconciliation event sequence, zero retry writes, and
