    textContent and className with SOURCE_LABELS and SOURCE_CLASSES maps.

    when pv_total_power is null.
  - New function renderInverterDetail(snapshot): fills compact detail row with
    AC input voltage, load %, charge current, discharge current. Section hidden
    when no inverter data available.
  - Updated cacheDom(): binds all new DOM element references including operator
    summary, source indicator, load tab elements, and inverter detail elements.
  - Updated renderSnapshot(): calls renderSourceIndicator, renderOperatorSummary,
    renderStartupReset (regression fix), and renderInverterDetail. Splits loads
    into activeRows (currently_on === true) and inactiveRows (all others).
    Renders into respective tbody elements.
  - Tab switching in start(): click handlers on #loads-tab-active and
    #loads-tab-inactive toggle is-active class and show/hide corresponding
    tbody elements.
  - All API values rendered via textContent (verified: zero innerHTML usages
    for any API-derived text).
  - Preserved: AbortController, visibilitychange, setTimeout recursion, 5-state
    connection machine, bounded retry, stale/offline timers.
  - renderSensors() unchanged — called from handleSuccessfulResponse as before.
  - handleSuccessfulResponse unchanged — same poll/render cycle.
