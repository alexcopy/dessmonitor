TITLE
PR 0036 — Compact Operator Dashboard Layout

INCIDENT
The authenticated dashboard now successfully shows inverter telemetry (battery
voltage, output power, PV power, etc.) after PR 0034l.  However, the operator
surface is not readable enough.

Observed operator complaints:
- Inverter metrics are rendered as 8 oversized KPI cards at the bottom of the
  page, below Current Loads and Sensors sections.
- The first viewport (above the fold) shows generic summary cards (System
  Status, Total Loads, ON/OFF/UNKNOWN counts) that do not convey the most
  important system state.
- Current Loads table occupies excessive visual weight and shows ALL devices
  (ON, OFF, UNKNOWN, stale) with no default active-device filter.
- OFF/unavailable devices distract from currently active devices.
- The operator wants a compact, transparent layout similar to a clean control
  console.
- No source indicator tells the operator whether the system is running on
  inverter/green energy or mains/grid.

Weather forecast was requested but is a separate data-source feature and must
not be bundled into this PR.

SOURCE-INDICATOR SEMANTICS

The source indicator is derived exclusively from existing proven fields
(snapshot.inverter[0].working_mode and snapshot.inverter[0].mains_status).

Source states:
- "inverter" — system is running on battery/PV (green energy)
  Triggered by working_mode in ("Battery Mode", "PV Mode", "Invert Mode",
  "Power Saving Mode", "Standby Mode", "Bypass Mode")
  Visual: green color, tree/leaf or battery icon (unicode/text)
  Label: "Inverter" or "Battery" or "Solar" depending on working_mode

- "mains" — system is connected to grid/utility power (line mode)
  Triggered by working_mode == "Line Mode"
  Visual: amber/blue color, lightning/plug icon (unicode/text)
  Label: "Mains" or "Grid"

- "unknown" — no inverter data or no working_mode available
  Triggered by empty inverter array or working_mode == ""
  Visual: grey color, dash icon
  Label: "N/A"

- "fault" — inverter reports fault mode
  Triggered by working_mode == "Fault Mode"
  Visual: red color, warning icon
  Label: "Fault"

The indicator is rendered as a colored badge/tag with an icon character and
one word of text.  No emoji, no oversized graphic — compact text + CSS class
(background color, text color, optional border).
