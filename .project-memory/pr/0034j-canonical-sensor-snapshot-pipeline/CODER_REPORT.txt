INCIDENT
Production sensors report temperature around 20.9 C through the ML and
inverter-summary compatibility path. The authenticated dashboard displays
"No sensors available" because the typed snapshot pipeline drops sensors
before serialization.

VERIFIED ROOT CAUSE
Seven exact data-loss points confirmed:
1. build_control_state_snapshot_from_runtime_state never reads
   runtime_state["sensors"].
2. RuntimeControlSnapshotAdapterInput has no typed sensors list field.
3. ControlStateSnapshotInput has no typed sensors list field.
4. ControlStateSnapshot has no sensors field.
5. FastAPI serialization only emits declared dataclass fields.
6. _parse_loads() drops description, device_type, mapping_status,
   startup_reset_result, enabled, communication_status from load dicts.
7. TelemetryRegistry.get_all_readings() drops description when recomputing
   SensorTelemetryReading.

CHARACTERIZATION TESTS
Before implementation, the test script confirmed all 7 data-loss points.
After implementation, all 58 checks pass.
