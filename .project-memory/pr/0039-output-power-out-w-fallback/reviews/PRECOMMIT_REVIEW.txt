IMPLEMENTATION SUMMARY
----------------------
One-line change in _parse_inverter() within runtime_snapshot_adapter.py:

Before:
    output_power=_safe_inverter_float(item.get("output_power")),

After:
    output_power=_safe_inverter_float(
        item.get("output_power") or item.get("out_w")
    ),

Python or-operator semantics: output_power direct value is used if truthy;
out_w is the fallback when output_power is None, absent, or 0.0.
_safe_inverter_float handles type coercion and NaN/Inf/bool safety for both.
