INDEPENDENT ROOT CAUSE FINDINGS

Each finding independently confirmed against HEAD cd0847a:

1. CONFIRMED. Path A — Primary request logger at app/api.py line 235:
     self.logger.info(f"[API] Выполняем запрос: {url}")
   The `url` variable at this point contains the complete signed URL with sign,
   salt, token, pn, devcode, devaddr, sn, source, _app_client_, _app_id_,
   _app_version_. This is an f-string format, so the full URL is interpolated
   into the log message at INFO level.

2. CONFIRMED. Path B — Primary request stdout at app/api.py line 238:
     print("The request URL >>>", url, "\n>>> ", end="", flush=True)
   Same complete signed URL printed to stdout, flushed immediately. Container
   stdout is captured by Kubernetes log aggregation.

3. CONFIRMED. Path C — Fallback request logger at app/api.py line 343:
     self.logger.info(f"[WEB] Выполняем запрос: {url}")
   The fallback URL constructed at lines 337-341 includes sign, salt, token, pn,
   devcode, devaddr, sn, i18n. Same f-string full-URL exposure at INFO level.

4. CONFIRMED. The logger used by DessAPI receives a loki_handler (app/logger.py).
   Line: lh = loki_handler(); if lh not in self.logger.handlers: self.logger.addHandler(lh)
   This means signed URLs flow to logs/loki.log in logfmt format, making them
   ship-able to Loki/Promtail/Grafana.

5. CONFIRMED. The _generate_sign method creates a sign parameter and salt parameter
   using the SHA-1 hash concatenating salt + secret + token + param_str. These are
   authentication credentials that prove request authenticity.

6. CONFIRMED. The authentication path flows through _do_api_request with
   need_auth=False. The params dict at line 264 includes usr (email) and
   company-key (organization identifier). These also appear in the logged URL.

7. CONFIRMED. Exception text analysis is accurate:
   - _do_api_request exception handler (line 253):
       raise RuntimeError(f"Ошибка запроса: {e}")
     where e is a urllib.error.URLError or HTTPError. In Python's standard
     library, HTTPError.__str__ returns "HTTP Error {code}: {reason}" — does
     NOT include the request URL. The URL is available as HTTPError.url attribute
     but is not part of the string representation.
   - fetch_device_data_fallback exception handler (line 351):
       raise RuntimeError(f"Веб-кролл не удался: {e}")
     Same analysis — exception str() does not carry the URL.
   - auth initialization warning (line 108):
       self.logger.warning(f"[API] Не удалось аутентифицироваться при
       инициализации: {auth_exc}.")
     auth_exc would be a generic RuntimeError from failed authenticate(), not the URL.
   - TokenExpiredError at line 245: constant string "token expired" — safe.

8. CONFIRMED. The complete signed URL is required unchanged for urlopen:
   - Line 239: with urllib.request.urlopen(url, timeout=120) as resp
   - Line 346: with urllib.request.urlopen(url, timeout=20) as resp
   The URL must carry all credential parameters for the DESS API to authenticate
   the request. The PLAN preserves the URL passed to urlopen unchanged.

9. CONFIRMED. PR0035 is the first incomplete canonical roadmap milestone.
   ROADMAP.md (post-PR0034k) defines the fifteen-PR sequence starting with
   PR0035. The PR0035 entry has Gate: None, establishing it as an independent
   security fix before any UI or observability work.
