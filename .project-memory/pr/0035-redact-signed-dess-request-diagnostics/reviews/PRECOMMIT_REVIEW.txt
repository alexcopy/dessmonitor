SAFE DIAGNOSTIC CONTRACT ASSESSMENT

_redact_url preserves:
- scheme (e.g., https)
- host (e.g., api.dessmonitor.com)
- path (e.g., /public/)
- action parameter (e.g., queryDeviceLastData, authSource, querySPDeviceLastData)
- i18n parameter (e.g., en_US)

_redact_url replaces with "REDACTED":
- sign, salt, token, usr, company-key
- pn, sn, devcode, devaddr
- _app_client_, _app_id_, _app_version_, source
