INDEPENDENT DATA-FLOW TRACE

Source boundary (DeviceData / InverterMonitor.last_data):

InverterMonitor stores DeviceData from DESS API in self.last_data (new field).
DeviceData carries all required fields: battery_voltage, battery_capacity (SOC),
battery_charging_current, battery_discharging_current, pv1_voltage, pv1_power,
pv2_voltage, pv2_power, pv_total_power, output_voltage, output_power,
output_apparent_power, ac_input_voltage, ac_input_frequency, ac_output_load,
working_state, mains_status, timestamp.

Values preserved as Optional[float] or Optional[str]. None means unavailable.

-> runtime_state["inverter"] (build_runtime_read_model via inverter_provider):

run.py defines _inverter_provider lambda: reads inverter_mon.last_data and
constructs a flat dict with normalized keys (battery_soc from battery_capacity,
working_mode from working_state). Returns None when last_data is None.

build_runtime_read_model receives inverter_provider callable, invokes it,
wraps result in a list: result["inverter"] = [inv_data].

Values preserved as float | None or str. Null dict keys omitted safely.

-> _parse_inverter() (runtime_snapshot_adapter.py):

Parses list of dicts into tuple[InverterReadSnapshot, ...].
Uses _safe_inverter_float() which rejects bool, NaN, inf.
All 22 fields mapped from dict keys to dataclass fields.
Invalid dict entries silently skipped (try/except).
None input or non-list/tuple returns empty tuple.

Values preserved. Null floats remain None. String defaults to "".

-> RuntimeControlSnapshotAdapterInput.inverter:

New field: tuple[InverterReadSnapshot, ...] = field(default_factory=tuple).
Values preserved with typed contract.

-> ControlStateSnapshotInput.inverter:

New field: tuple[InverterReadSnapshot, ...] = field(default_factory=tuple).
Values preserved.

-> ControlStateSnapshot.inverter:

New field: tuple[InverterReadSnapshot, ...] = field(default_factory=tuple).
Values preserved.

-> FastAPI serialization -> JSON "inverter" array:

Frozen dataclass serialized by FastAPI built-in encoder.
Values preserved. Null floats serialize as JSON null.

-> Dashboard rendering contract (dashboard.js renderInverter()):

Reads data.snapshot.inverter, checks non-empty array.
formatValue() renders null/undefined as "N/A", non-null values with unit suffix.
Uses textContent exclusively. No innerHTML.

TYPED CONTRACT ASSESSMENT

InverterReadSnapshot (app/control/control_state_snapshot.py):
- Frozen dataclass with 22 fields
- All numeric fields: float | None = None (nullable)
- String fields: str = "" (non-nullable defaults)
- observed_at: str | None = None (nullable ISO timestamp)
- source: str = "dess" (default data source label)
- freshness: str = "" (computable from observed_at, deferred to future PR)
- status: str = "" (inverter communication status placeholder)
- Units: V (voltage), W (power), VA (apparent power), A (current),
  % (SOC, load), Hz (frequency) — documented in field semantics
- No Tuya IDs, property codes, device IDs, parent IDs in any field
- No SensorReadSnapshot contamination (separate type for temperature-only domain)
- No load_in_wt or configured_load_watts conflation
- Serialization: FastAPI native dataclass serialization, null floats -> JSON null

The contract is coherent, domain-separated, and meets the typed boundary
requirement. Inverter fields are NOT added as loose top-level values.
