⚠ Overload Protection — Help

Protection Levels

OKBattery discharge normal (<55A). System running fine.
SOFTBattery discharge >55A for >5 min. Alert only — no action taken. Monitor the situation.
HARDBattery discharge >65A for >2 min. Starts turning off high-power devices one by one (highest priority number first, ≥100W only).
CRITICALOutput power >2000W for >5 min. Turns off all non-essential devices.

Event Format

OK → SOFTSystem entered soft alert. dis = battery discharge current (A), pwr = output power (W).
SOFT → HARDEscalated to hard alert. Device shedding will start.
HARD → OKOverload resolved — current dropped back to normal.
HARD shed → X OFFDevice X was automatically turned off to reduce load. Priority number shown — higher number = less important.

Why does it happen?

Usually when solar panels are suddenly shaded by clouds while high loads (heater, pump) are running. The battery compensates but risks overheating.

Thresholds

SOFT: >55A | HARD: >65A | CRITICAL: >2000W
Priority 1 devices (e.g. main pump) are never shed. Devices <100W are skipped.
